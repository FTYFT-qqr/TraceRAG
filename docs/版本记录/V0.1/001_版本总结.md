# V0.1 版本总结

- 版本范围：本地知识库问答基础链路
- 状态：2026-09-28 已冻结
- 整理日期：2026-10-04

## 版本范围

完成配置、PDF/Markdown/TXT 解析、页码与 Chunk 来源、Embedding、FAISS 快照、向量 Top-K、证据约束回答、引用、拒答、FastAPI 和 Streamlit。支持本地模型或 OpenAI 兼容服务、相同文件跳过、同名内容替换、旧快照迁移和完整向量空间身份校验。

当时八项冻结条件为：三种格式成功导入、PDF 页码保留、Chunk 可追溯、向量索引建立、Top-K 上限一致、基于检索证据作答、返回来源引用、证据不足拒答且状态一致；基础整改九项均完成。细节见[002 整改与验收](002_整改与验收.md)。
