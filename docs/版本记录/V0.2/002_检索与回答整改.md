## 验收边界修复

2026-10-01 修复五项可复现缺陷。最初已有的 105 项回归未覆盖这些边界，补齐后 170 项通过、2 条依赖弃用提示、10.08 秒。

| 原问题 | 失败行为 | 修复与验收要求 |
| --- | --- | --- |
| 02-2.1 数值 | 小数点被移除，使 40 小时与 4.0 小时错误等同 | Decimal 核对完整值，保留小数、负号及数字边界；支持中文、裸数字及 `.5`；错误量级失败，等值小数允许 |
| 02-2.2 完整断言 | 命中“未列出费用”后附加“终身免费维修”仍通过；后置否定反转未识别 | 连接词后的断言和短语剩余部分继续核验；额外说法待复核，“不可借用是不正确的”判失败；共享否定、短确认、单位纠正正常支持 |
| 02-2.3 逐句引用 | 多句引用颠倒，因证据集合含事实而错误通过 | 每句按自己的编号限定来源；错号/无效号失败；缺引用、跨句统一尾注待复核；同一断言多条支持证据允许 |
| 02-2.4 相关度 | 将归一化 RRF 首名视为 1，零相关候选越过余弦门槛 | RRF 保存原始排序分；向量/BM25 各用原始门槛，零 BM25 不参与融合；Hybrid 任一路支持仅是生成前筛选 |
| 02-2.5 退出码 | 质量失败且 errors=0 时 CLI 返回成功 | 质量模式必须执行并满足 `acceptance_pass`；失败或复核返回 1，通过返回 0；套件纯检索轮另按检索条件判断 |

共用评分要求见[评测标准](../../评测数据/评测标准.md)，该轮检索配置与结果见[边界修复对照 JSON](../../评测数据/版本0.2/验收边界修复_2026-10-01/检索对照/对照摘要.json)。同组等义表达仅允许已经声明的接受方式，不放宽数字、极性、额外说法与引用错配规则。

## 回答协议与检索整改

2026-10-03 对 10 月 1 日保存的 100 个回答逐题复核，记录 48 个自动未通过项。修复始终使用相同 50 题与三份语料，保留失败的中间结果。

| 问题 | 实施要求与结果 |
| --- | --- |
| 等义事实误报引文不支持 | 同一句引用可使用事实组内另一接受表达；未知完整断言继续人工复核 |
| 自由改写无法自动核实、引用格式遗漏 | 改为模型选择已存在的短句编号 JSON，代码还原原文并逐句绑定来源 |
| 模型复制原文产生大量协议错误 | 取消让模型复制文字，保留失败报告；无效 JSON、伪造编号、拒答夹引用均明确报错，不回退自由文本 |
| 分号拆开导致预约手续缺项 | 分号关联的条件与手续保留在一个选择单元，展示时每分句仍绑定引用 |
| 跨文档相似规则混入 | 提示要求覆盖所问主题，评测检查引用文件是否属于预期来源 |
| 向量漏召回导致误拒答 | Runtime 接入 vector/bm25/hybrid；稀疏表从快照 Chunk 建立，同名更新和恢复后刷新 |
| 融合分误当相关度 | API 返回 `score_kind` 及两路原始分；界面标注余弦、BM25、RRF 排序分 |
| 相同提示下代码变化难追溯 | 报告保存原文选择协议、提示与关键实现 SHA-256 |

`grounded_answer.py` 负责选择单元和输出校验，`chat.py` 负责模型请求，`evaluation.py` 负责评分，`runtime.py` 负责组合检索器；完整职责见[系统架构](../../使用指南/系统架构.md)。
