## 升级、配置与回退

- 包元数据、包内版本、默认 API 和示例配置统一为 `0.2.0`；自定义 `TRACERAG_VERSION` 可覆盖默认值，旧配置应同步版本字段。
- 快照格式及 Embedding 身份方案未因发布变更。同一模型、端点和路径可恢复旧索引；Windows 转入 Linux 容器后路径不同，使用独立卷重新导入。
- 策略切换调整 `TRACERAG_RETRIEVAL_STRATEGY` 并重启 API，无需重建相同模型的向量快照。兼容默认配置为 vector，本地验收配置及容器示例使用 hybrid。
- BM25 原始分门槛默认 0，RRF-K 默认 60；余弦门槛独立配置，RRF 分仅排序。
- `.env`、`.env.docker`、权重、索引和临时测试目录不纳入发布。部署步骤见[容器部署](../../使用指南/容器部署.md)。

## 交付状态与已知范围

本地候选分支 `codex/full-delivery-v0.2`、候选标签 `v0.2.0-rc.1` 已有记录。Docker 已迁至 D 盘；最终 Windows、Linux、CPU 镜像各 220 项回归、固定协议 9 项、真实模型与恢复 19 项检查通过。正式提交与标签尚待另一轮文档整理收尾，远程 CI 未运行。正式标签是否完成以[004 工程交付验收](004_工程交付验收.md)为准，不沿用历史“Docker 未实测”的结论。

原始报告保留运行当时的配置、代码和输入指纹。包版本统一导致 `app/config.py` 指纹变化，旧报告不能当作后续版本刚重跑的结果。

当前不提供认证、知识库空间、文档列表/删除、OCR、Word、自由改写、翻译、多轮对话和流式输出；快照写入按单 API 进程设计。原文回答可能保留条件及同来源上下文，不能仅凭文字来自原文证明答案完整。后续新题集与新规划分别归档，不覆盖本批输入输出。
