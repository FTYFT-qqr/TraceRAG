## 存放规则

1. 版本规划写入 `docs/项目规划/版本X.Y/`；总体路线集中在 [开发路线图](项目规划/开发路线图.md)。
2. 整改写入 `docs/整理记录/版本X.Y/整改记录/`，使用连续两位编号和中文主题；人工分析、结论按对应评测轮次另存。
3. 自动报告写入 `docs/评测数据/版本X.Y/轮次名称/`；逐题 `.md` 与 `.json` 保持同名，新增运行使用新目录。
4. 文件和目录使用中文名称，保留 BM25、RRF 等技术缩写；历史失败报告保留并在整理结论中说明。
5. 评测输入题集和样例语料位于 `samples/acceptance/`；应用上传文件与索引属于运行数据，路径见项目 README。

此次目录调整说明和旧路径查找方式见 [目录调整说明](整理记录/文档管理/目录调整说明.md)。
