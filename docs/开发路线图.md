# TraceRAG 开发路线图

- 适用范围：原定项目范围与后续方向
- 更新日期：2026-10-04

## 项目目标

面向 AI 应用工程展示的可溯源知识库问答系统。原定完整版由下列十个模块组成，重点是文档导入、检索、证据约束回答、评测迭代和可复现交付。

## 原定模块与状态

| 模块 | 交付要求 | 当前状态与证据 |
| --- | --- | --- |
| 1. 项目骨架与配置 | 依赖、配置、日志及健康检查 | 已实现；[本地启动](../README.md#本地启动) |
| 2. 文档加载 | PDF/Markdown/TXT，保留文件名与 PDF 页码 | 已实现；[V0.1 总结](版本记录/V0.1/001_版本总结.md) |
| 3. 文本切分 | 带重叠的 Chunk、唯一编号及来源元数据 | 已实现；[系统架构](使用指南/系统架构.md) |
| 4. Embedding 与索引 | 本地或兼容 API、FAISS、快照保存恢复 | 已实现，另有模型身份与事务保护；[V0.1 整改](版本记录/V0.1/002_整改与验收.md) |
| 5. 检索 | 查询、Top-K、文本和原始相关度分 | 已实现；[检索整改](版本记录/V0.2/002_检索与回答整改.md) |
| 6. 回答、引用、拒答 | 使用检索证据，引用可追溯，证据不足拒答 | 已实现原文短句选择协议；[评测标准](评测数据/评测标准.md) |
| 7. API 与界面 | 上传、提问、答案、来源和检索结果 | 已实现；[演示指南](使用指南/演示指南.md) |
| 8. 离线评测 | 约 50 题、检索/事实/引用/拒答、可追溯输出 | 固定 50 题已完成；[评测记录](版本记录/V0.2/003_评测与人工复核.md) |
| 9. 检索迭代 | BM25/RRF、单变量对照、Bad Case 前后分析 | 已实现；最终两策略质量各 43/43，拒答各 7/7 |
| 10. 工程与展示 | Docker、独立安装、测试、架构、Demo、发布 | 本地及容器验收、远程 Windows/Linux 各 222 项回归、Docker 检查和 5 分 33 秒浏览器演示已通过；正式版本入口及证据见[005 发布收尾](版本记录/V0.2/005_发布收尾与下一阶段规划.md) |

V0.1 于 2026-09-28 冻结基础链路；V0.2 于 2026-10-03 达到固定样本质量冻结条件。工程交付在后续独立环境和容器中验收，质量冻结与发布固化分别记录。

## 可选扩展

这些能力超出原定十模块范围，尚未作为当前版本完成条件：

| 方向 | 尚缺能力 | 选择依据 |
| --- | --- | --- |
| 检索与评测 | Reranker、跨 Embedding 模型质量/成本对照、更广业务题集 | 新数据出现漏召回或排序问题时，先固定样本再对照 |
| 文档管理 | 文档列表与删除、知识库空间、认证与权限 | 有多人或多知识库需求后再定数据隔离方案 |
| 文档解析 | OCR、扫描件、图片、复杂表格、Word、网页 | 根据真实资料格式补充解析及来源定位 |
| 回答体验 | 自由改写、翻译、多轮会话、流式输出 | 扩展时须维持逐句来源与拒答验收 |
| 部署与性能 | 大规模并发/延迟评测、监控、模型依赖完整锁定 | 远程工程 CI 已实测；后续先定义运行规模和资源约束，再验证 |

同模型的批次配置对照不代表跨模型对照；三份语料、50 题的通过不代表任意业务问题均正确。新增本地裁判模型按既有决定暂缓。

## 后续规划规则

用户确认本轮仅完成 V0.2 发布与演示；V0.3 文档列表与删除仍是后续建议，尚未实现。后续按实际使用问题选择扩展，每次新规划放入对应版本的独立编号文件，参见[文档维护规则](README.md#文档维护规则)。
