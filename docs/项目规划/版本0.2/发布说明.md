# TraceRAG 0.2.0 发布说明

## 实现范围

- 完整本地 RAG 链路：解析、切分、向量快照、模型身份、重复跳过与同名更新。
- 在线 vector/BM25/RRF 混合召回及独立证据门槛。
- 模型只选择完整原文短句编号，代码生成文本和逐句引用。
- 固定 50 题的检索、事实、引用和拒答评测；失败与待复核阻止质量验收。
- 中文文档按项目规划、整理记录、评测数据归档。
- Docker API/UI 配置、本地模型挂载、快照卷、架构图、演示步骤与工程验收脚本。

包元数据、包内版本、默认 API 和示例配置统一为 `0.2.0`；已有自定义 `TRACERAG_VERSION` 可覆盖默认值，旧配置升级时应同步更新。

## 证据与状态

真实模型验收见 [质量验收结论](../../整理记录/版本0.2/质量整改_2026-10-03/验收结论.md)：固定样本 BM25/混合召回均质量 43/43、拒答 7/7。工程验收与 Git 固化状态见 [交付验收记录](../../整理记录/版本0.2/工程交付/交付验收记录.md)。

旧报告中的代码指纹记录当时文件；本轮仅因包版本统一修改 `app/config.py`，该文件指纹与旧记录不同。回答、评分与检索实现未因发布工程而更改，旧结果保持原样，不能声称旧配置指纹仍完全对应本轮发布。

## 升级与回退

本轮不变更索引快照格式或 Embedding 身份。使用同一模型、端点和路径时可恢复现有索引；进入容器后模型路径与主机不同，应使用独立卷重新导入。策略切换调整配置并重启 API。

版本提交不纳入 `.env`、`.env.docker`、权重、索引、测试临时目录及编辑器配置。通过 Git 提交和标签在本地固定；远程发布需要另行指定远程目标。

## 已知范围

尚不提供用户认证、知识库空间、删除接口、OCR、Word、自由改写、翻译、多轮对话与流式输出。当前快照写入按单 API 进程设计。真实模型质量只在现有固定题集上验证。
