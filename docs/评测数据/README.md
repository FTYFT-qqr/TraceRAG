## 新运行与保存规则

每轮使用新的目录，命名可用 `主题_日期_轮次`，不覆盖上述冻结记录。脚本会输出 JSON 和 Markdown；整理归档时保留完整 JSON，最终发布生成一份对照摘要，无 JSON 替代的结果保留原始 Markdown。

题集路径及指纹保留运行当时的值，目录整理不会改写 JSON 内的历史路径。解释性总结引用原件，避免再复制整份机器报告。根目录[README](../../README.md#评测与验收)给出运行命令。
