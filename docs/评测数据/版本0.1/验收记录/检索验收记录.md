归还图书可以放在一楼服务台，也可以使用入口旁的24小时还书箱。还书箱每天上午9点统一清空，晚上投入的图书会在次日上午登记归还。图书遗失或明显损坏时，读者应到服务台说明情况并填写处理登记表；本手册不列出赔偿金额，具体处理由馆员根据图书情况告知。

图书馆每月第一个周六上午举办亲子阅读活动，需在活动开始前一天通过服务台登记。活动名额满后会停止登记。馆内不提供图书配送或读者寄存柜服务；自习区、少儿阅读室和借还服务均按本手册所列开放安排执行。

图书馆三楼设有地方文献阅览角，资料仅供现场阅读，不计入普通图书借阅数量。读者查询馆藏时可以使用入口处的自助检索终端，终端显示书架区域和索书号；若系统显示“整理中”，可向一楼服务台询问预计上架时间。报刊阅览区每天随图

光谱仪仅供经过实验室安全培训的成员使用，初次借用前需在系统中完成培训确认。未经预约不得直接取用设备；不得将设备转借给其他成员，也不得把设备放入还书箱或无人值守的储物柜。设备柜台电话在工作时段接听，未接来电会在下一个开放时段处理。

实验室另有便携式温湿度记录仪和数字卡尺，借用方法与光谱仪类似，但预约时必须选择各自的设备编号。设备柜台不接受口头代预约；课题组负责人可以协助填写申请，但实际使用人仍需本人签收。临时取消申请时，请在预约单上注明原因，避免管理员重复准备设备。

实验室另有便携式温湿度记录仪和数字卡尺，借用方法与光谱仪类似，但预约时必须选择各自的设备编号。设备柜台不接受口头代预约；课题组负责人可以协助填写申请，但实际使用人仍需本人签收。临时取消申请时，请在预约单上注明原因，避免管理员重复准备设备。
