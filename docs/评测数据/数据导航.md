## 新数据存放

- 新运行写入 `版本X.Y/中文轮次名称/`，同轮可按召回策略分子目录。
- 自动逐题 `.json` 与 `.md` 使用相同文件名，自动摘要仍与该轮数据放在一起。
- `scripts/evaluate_v02.py` 默认输出到 `docs/评测数据/版本0.2/临时运行/`；正式归档应通过 `--output-dir` 指定新的轮次目录。
- `scripts/evaluate_retrieval.py` 默认输出到 `docs/评测数据/版本0.1/验收记录/检索验收记录.md`。
- 输入题集与公开语料位于 `samples/acceptance/`，由脚本直接读取。
