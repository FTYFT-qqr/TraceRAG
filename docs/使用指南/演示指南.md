## 真实模型演示（约五分钟）

在独立环境或容器知识库中启动服务，避免把演示语料加入日常资料索引。仅使用已验收的三份公开样例：

- `samples/acceptance/lab_equipment.txt`
- `samples/acceptance/library_service.txt`
- `samples/acceptance/clinic_service.txt`

| 步骤 | 操作 | 展示要点 |
| --- | --- | --- |
| 1 | 打开 UI，上传三个样例文件 | 文件名、解析页数、片段数和入库成功 |
| 2 | 重复上传实验室样例 | 已有文件跳过，无重复片段 |
| 3 | 从题集选择 `LAB-V2-02` 的完整原问题 | 提前预约、必填信息、柜台确认均回答，并逐句标注来源 |
| 4 | 选择 `LAB-V2-07` 的完整原问题 | 支持“未列出”的否定事实并给出手册规定的下一步，不混入图书馆规则 |
| 5 | 选择 `CLINIC-V2-11` 的完整原问题 | 由间接地点证据给出“一楼登记台”，展示两个前提 |
| 6 | 选择题集中 `answerable=false` 的问题 | 证据不足时拒答，无引用 |
| 7 | 展开来源与检索结果 | 原文、文件名、候选排序、RRF 类型和原始通道分 |
| 8 | 重启 API 后重复步骤 3 | 无需重新上传，快照恢复后仍可回答 |

原问题以 `samples/acceptance/questions_v02.json` 为准，演示不自行缩写。当前 API 未保存原始上传文件，仅保存切分文本和向量快照。

容器启动与重启命令见[容器部署](容器部署.md)。录屏按上述步骤进行，避免拍入配置密钥。

## 不使用外部模型的工程演示

```powershell
python scripts/delivery_smoke.py --output-dir docs/评测数据/版本0.2/工程交付_新轮次
```

自动演示固定设备文件的上传、回答“最长4小时”、对未知购买价格拒答、同名更新和进程重启恢复。API、Chat/Embedding 协议及 FAISS 都经真实 HTTP 调用；模型语义是固定响应，仅用于工程验收。输出报告中的 `mode=offline-fixed-protocol` 明确标记范围。

此命令使用独立临时索引和空闲端口，不读取真实模型凭据，不影响已有知识库；输出目录必须新建，历史记录不会被覆盖。

## 简历项目表述

> TraceRAG 可溯源知识库问答：基于 FastAPI、Streamlit、FAISS 和本地 Embedding 构建 PDF/Markdown/TXT 导入与问答链路；实现模型身份校验、同名替换和快照恢复，结合 BM25 与 RRF 混合召回，通过原文短句编号选择与逐句引用约束回答。建立固定 50 题离线评测，BM25 和混合召回在该样本上均达到有答案质量 43/43、拒答 7/7，并提供 Docker 配置与独立工程验收脚本。

工程测试数量和容器实测范围见[工程交付验收](../版本记录/V0.2/004_工程交付验收.md)。五个容器定向场景的结果单独记录。
