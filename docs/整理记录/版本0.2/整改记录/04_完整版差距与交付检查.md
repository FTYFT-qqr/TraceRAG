## 4. 可选扩展及当前产品限制

以下内容尚未实现，但原定路线没有把它们全部列为必须交付：

- Reranker：路线规定在前九个模块稳定后再考虑；目前没有重排序模型。
- 不同 Embedding 模型的真实对照：已有同模型批次配置对照，尚无跨模型质量与成本比较。
- 更广业务评测与性能对照：当前通过的是三份样例的固定 50 题，未形成大规模、多领域、并发或延迟评测结论。
- 文档管理：删除、列表、知识库空间和用户权限尚未提供；当前主要 API 是健康检查、上传与查询。
- 解析扩展：OCR、扫描件、图片、复杂表格、Word 和网页导入尚未提供。
- 回答体验扩展：当前模型选择原文短句，代码确定文本和引用；自由改写、翻译、流式输出和多轮会话未作为已实现能力交付。
- 持续验证与部署可复现性：已加入 CI 配置和核心交付依赖约束；远程 CI 未运行，可选模型依赖未完整锁定，监控仍属扩展。

新增本地裁判模型按用户之前决定暂缓，不计入当前必做缺口。
