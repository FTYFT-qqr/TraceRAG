### 7.6 避免误拒答有证据的否定事实

**现状：** 回答中只要出现“未列出”“未提供”等词，`RAGService` 就会按拒答处理。文档明确写着“本规定未列出维修费用”时，针对“是否列出维修费用”的正确回答即使带有效引用，也会被误拒答。

**改动：** 区分“文档明确说明未提供某项信息”的可引用事实与“无法回答具体数值”的拒答。拒答判定不应仅凭回答中出现否定词；可以采用明确的整句拒答格式或结构化拒答状态，并保留证据不足时的保守处理。

- [x] 验收：有证据的问题“本规定是否列出维修费用？”和同义问法“文档有写维修费用吗？”均能引用回答“未列出”；单独询问“维修费用具体是多少？”仍拒答；同时询问具体数额及文档有无记载时，回答受证据支持的“未列出”事实并引用。以上场景均有回归测试和真实样本逐题记录，见 LAB-05–LAB-07、NONE-04。

**2026-09-26 复核与修复：** 查询意图识别现覆盖“有写/写明/提及/列出”等常见同义表达；针对是否记载的问题扩大候选检索范围，让模型能取得明确的否定证据。答案生成提示要求直接回答“未列出”，并避免用“文档提到了费用”造成歧义；混合问题可回答可证实的记载状态，单独索取具体数值仍拒答。

**验收结果：** 定向拒答回归通过；真实样本 14/15 条证据位于 Top-5、15/15 条答案质量通过，4/4 条具体缺失信息问题正确拒答，0 条执行错误。全部问答及引用详情见验收记录。

### 7.7 完整标识 Embedding 向量空间

**现状：** 索引身份仅包含 provider 与模型名或本地目录路径。不同远程接口使用同一模型别名，或原路径下的本地模型权重被替换时，当前比较仍认为索引兼容。

**改动：** 远程 Embedding 身份加入规范化且不含凭据的服务端标识及模型名；本地身份加入模型目录内容的 SHA-256 指纹。索引元数据与当前配置比较时，身份变化应明确提示重新建索引，不能静默复用旧向量。缺少新身份字段的旧快照按旧格式迁移，使用当前模型从保存的 Chunk 重建向量。

- [x] 验收：相同模型别名但不同远程服务地址不能共用索引；同一路径替换本地模型权重后不能复用旧索引；未变化的模型仍可正常加载。以上场景均有向量库回归测试，旧格式迁移有运行时测试。

### 7.8 让验收通过条件覆盖回答质量

**现状：** 当前验收脚本的退出状态只统计有答案问题的 Top-5 证据命中和无答案问题拒答。即使有答案问题被拒答、回答错误或引用不支持回答，也可能显示“通过”。

**改动：** 为有答案问题记录预期事实、是否正常回答、回答是否正确及引用是否支持该事实。自动通过条件至少要包含正常回答和有效引用；事实正确性可通过明确的预期答案核对或人工复核并记录，不得仅凭检索命中宣称问答通过。单题执行错误也应计入失败。

- [x] 当轮验收：阿拉伯数字 14小时/4小时、已覆盖的否定反转、错误引用、独立分句的额外事实和执行异常场景通过；实际样本为 15/15 条有答案质量通过、4/4 条正确拒答。中文数字与同句额外事实的后续遗漏见独立规划 003。

**2026-09-26 复核与修复：** `_assess_case` 现在按完整数值边界匹配事实，检查答案中的否定反转、数值是否由引用支持，并核对每项预期事实都有引用依据。新增事实子句无法自动核验时记录为“待人工复核”，只有人工确认或自动核验完成才允许通过；Top-5 指标严格按前五名计算，即使某类问题扩大了实际候选集也不虚报 Top-5 命中。

**验收结果：** 数字、否定反转、无证据数值、额外未核实子句、引用映射和 Top-5 计数均有定向用例；完整 pytest 80 项通过。真实模型验收 15/15 条有答案问题质量通过、4/4 条拒答正确、0 条待人工复核、0 条执行错误。逐题记录见 [检索验收记录](../../../评测数据/版本0.1/验收记录/检索验收记录.md)。
