- 日期：2026-09-26。
- 状态：已实施；本规划三项及配套标准 004 的验收均通过。
- 来源：最近一次完成情况复核；沿用问题编号 7.2、7.8、7.9，便于追踪历史。

## 1. 拒答优先级（原编号 7.2）

**实施前复现（2026-09-26）：** `_is_refusal` 曾先在“是否记载”问题且答案含“未列出”等词时返回 `False`，再检查明确拒答语，导致拒答优先级被绕过。问题“文档有写维修费用吗？”下，模型输出“根据当前知识库，我无法确认这个问题。资料未列出维修费用。[1]”时，曾返回 `rejected=False` 并附 1 条引用。

**本轮改动：** 明确拒答判定移到信息存在性例外之前；普通问题、是否记载和混合问题均覆盖固定拒答语加否定事实、附引用编号的回归用例。单独回答有证据支持的“未列出”事实仍正常作答并引用。

- [x] 明确拒答在普通问题、是否记载类问题和混合问题中均返回拒答状态及空引用。
- [x] 仅回答受支持的“未列出”事实时，仍可正常作答并引用。

## 2. 回答质量评分（原编号 7.8）

**实施前复现（2026-09-26）：** 阿拉伯数字 `14小时` 可以识别，但中文“十四小时”仍会包含预期短语“四小时”。若答案为“本规定未列出维修费用且所有维修均禁止开展。[1]”，原评分器也会被正确短语掩盖额外断言。

**本轮改动：** 常用中文整数、逐位数字和小数规范化后与阿拉伯数字按完整数值和单位匹配；答案子句按“且”等连接词拆开分别核查，同句的无证据补充会标记为待人工复核并阻止总体验收通过。保留原有阿拉伯数字边界、否定反转、引用映射和独立额外分句场景。

- [x] “十四小时”和“四小时”按完整数值区分，错误回答不能自动通过。
- [x] 同一句中用“且”等连接词夹带的无证据事实不能随正确短语一起被放行。
- [x] 未能自动核实的事实转人工复核，并阻止整体验收通过。
- [x] 保留已有阿拉伯数字、否定反转、引用映射和单独额外分句的回归场景。

## 3. Top-K 设置与参考范围（原编号 7.9）

**实施前现状：** 是否记载类问题在 `RAGService.query` 内将请求的 `top_k` 增加 5，并把全部候选交给模型、返回 API；用户指定 `top_k=1` 时曾返回 6 个片段。

**本轮改动：** 是否记载问题仍可内部多取 5 个候选，只将最多 `top_k` 段交给模型并放入 API 返回列表；若扩展区间中有同主题且明确写明未列出的片段，可替换最终列表末位候选。每段保存原始候选排名，验收仍按扩展前的真实名次计算 Top-5。API 限制 `top_k` 为 1–20，界面说明和滑块名称均明确 Top-K 是最终供模型参考及展示的最大段数。

- [x] 验收：普通问题及是否记载类问题在 `top_k=1`、`5`、API 上限 `20` 均验证模型输入和返回数量不超过 K；扩展候选的同主题否定证据仍可作为最后一段引用，原始第 6 名及之后排名不计作 Top-5 命中。

## 4. 实施顺序与完成条件

1. 修复拒答判断顺序。
2. 补齐中文数字和同句额外事实的评分核验。
3. 统一内部候选数量、最终参考数量与界面说明。
4. 按上述场景补充回归测试，再运行基础测试和真实样本验收。
5. 在本文记录修改与验收结果；版本总览仅更新状态和链接，再判断能否冻结第一版。

此前的 80 项测试和真实模型指标属于实施前历史记录，不覆盖本轮新增场景。最新完整测试和真实样本结果见 [基础测试记录](../验收记录/基础测试记录.md) 与 [真实样本记录](../../../评测数据/版本0.1/验收记录/检索验收记录.md)。

## 5. 本轮实施与验收结果

- 拒答优先和拒答文本/状态/引用一致性：普通、是否记载、混合及无答案场景均有回归覆盖；正确回答否定事实仍可引用。
- 回答质量：新增中文“十四小时/四小时”边界、中文/阿拉伯数字等值、同句“且”连接的额外断言、人工复核阻断测试；此前的数字、否定反转、错误引用、独立额外分句及执行异常用例继续通过。
- Top-K：普通与是否记载类问题在 K=1、5、20 检查候选请求、模型输入数量、API 返回数量和否定证据引用；API 允许 20、拒绝 21；扩展候选的原始排名继续用于 Top-5 统计。
- 完整 pytest：91 passed、0 failed、0 errors，11.69 秒；有 2 条第三方弃用提示。
- 真实模型验收：Top-5 证据命中 14/15，回答质量 15/15，无答案正确拒答 4/4，待人工复核 0、执行错误 0；报告记录每题实际参考片段数和拒答文本/引用状态。
- 自动事实核验仍是基于验收事实和引用片段的规则核对；无法确认的内容保留待人工复核状态，不宣称为通用语义事实判定。
