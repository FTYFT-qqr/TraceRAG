# 005 LLM 证据约束专项验收

## 1. 轮次信息

- 版本：V0.1
- 状态：已完成
- 日期：2026-09-28
- 目的：补齐 V0.1 冻结标准中“LLM 仅使用检索证据回答”的最终确认。

## 2. 验收范围

本轮使用真实运行链路进行黑盒核验，覆盖：

1. 文档明确支持的事实：回答必须匹配文档事实并带可追溯引用；
2. 文档没有提供的事实：必须正确拒答，并且不得生成引用。

逐题输入、输出和结论保存在 [V0.1 检索证据约束专项确认记录](../验收记录/证据约束确认记录.md)。

## 3. 验收结果

| 场景 | 预期 | 实际 | 结果 |
| --- | --- | --- | --- |
| 有证据事实 | 回答“最长 4 小时”，引用对应文档 | 回答匹配事实，`rejected=false`，引用对应样本文档 | 通过 |
| 无证据事实 | 拒答且引用数量为 0 | 返回“根据当前知识库，我无法确认这个问题。”，`rejected=true`，引用数量为 0 | 通过 |

## 4. 结论

专项验收通过。结合基础回归测试、真实样本检索验收和本记录，V0.1 的冻结标准已全部满足，可以进入 V0.2 规划。

## 5. 后续

V0.2 的第一轮单独记录在 [V0.2 版本规划](../../../项目规划/版本0.2/版本规划.md)，不继续追加到 V0.1 文档。
